#### 🔬 Thesis — Hardware-in-the-Loop Test System for Medical Refrigeration Devices
> *Manipal Institute of Technology · 2024*

Designed and implemented an automated **STM32-based HIL test system** to validate daughter boards used in Emvólio medical-grade portable refrigeration devices. The system performed parametric verification of communication interfaces, power rails, and sensor outputs against defined acceptance criteria, with structured test reporting integrated into manufacturing quality control workflows.

```
System Architecture:
┌─────────────┐    SPI/I2C/UART    ┌──────────────────┐    Pass/Fail    ┌──────────────┐
│  STM32 HIL  │ ─────────────────► │  Daughter Board  │ ──────────────► │  Test Report │
│  Controller │ ◄───────────────── │  Under Test      │                 │  (Structured)│
└─────────────┘    Stimulus/Resp   └──────────────────┘                 └──────────────┘
         │
         ▼
  Power rail monitoring
  Sensor output verification
  Communication protocol validation
```
